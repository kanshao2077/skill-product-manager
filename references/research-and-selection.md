# 调研与选型协议

用于在新建或重做 Skill 前寻找可复用底座。目标不是拼装最多的现成方案，而是在相同约束下找到最小、可靠、可解释的实现。

## 1. 先固定能力合同

检索前先写清以下内容，后续候选都按同一份合同评估：

- 输入：用户会提供什么，允许缺少什么。
- 输出：必须交付什么格式、质量和边界。
- 环境：目标 Agent、可用工具、网络、文件和系统限制。
- 权限：完成任务所需的最小权限。
- 成功标准：至少 3 个代表性测试，包含正常、边界和失败场景。
- 非目标：本次明确不解决什么。

需求尚不完整但不影响方向时，用明确标注的合理假设继续；会改变能力边界、权限、依赖或数据安全时，再向用户提问。

## 2. 按顺序检索

1. **本地优先**：检查已安装 Skill、当前工作区、用户提供的材料和可复用脚本。先避免重复建设。
2. **官方其次**：检查目标平台规范、官方示例和一手文档，确认目录、元数据、触发方式及安全限制。
3. **社区最后**：搜索公开 Skill、仓库、目录站和成熟实践，补充官方材料未覆盖的工作流。

`find-skills`、`npx skills find <关键词>` 或同类目录工具只是可选发现入口，不是权威来源，也不是自动安装许可。找不到这些工具时，直接使用其他可用检索方式，不得因此中断。

宽搜阶段最多保留 8 个真正相关的候选；依据合同、来源质量和实现差异筛到最多 3 个做深评。相关候选不足时如实减少，不用凑数。

## 3. 先过硬门槛

任一项不通过，候选不得成为底座：

- **许可证**：有明确许可证，且允许预期的复制、修改和分发；无许可证时只可观察公开行为与独立总结思路，不复制内容。
- **权限**：权限范围可解释且符合最小权限；索取无关账号、密钥、全盘访问或危险系统权限则淘汰。
- **维护**：维护状态可判断；已归档、关键问题长期无人处理或与当前平台明显不兼容则淘汰。小而稳定、无需频繁更新的纯文本方案，可在完成审阅后注明例外。
- **依赖**：依赖来源可信、数量和体积合理、版本可约束、目标环境可用。评估阶段不安装新依赖。
- **安全**：未发现凭据收集、隐蔽外传、破坏性命令、提示注入接力或不可审计的下载执行链。

只读取候选的文档、清单和源代码进行审查；**不得运行第三方安装脚本、初始化脚本、测试脚本或仓库内命令**。若必须动态验证，先隔离、说明风险，并取得用户明确授权。

## 4. 用同一测试做 PK

对通过门槛的候选执行同一份能力合同和同一组测试，不因候选特点临时换题。若不能安全执行，就做静态走查并标记“未实测”，不得把推测写成通过。

按以下维度记录证据，而不是只给总分：

- 合同覆盖：必需输入、输出和异常路径是否齐全。
- 结果质量：代表性测试是否稳定达到成功标准。
- 可移植性：是否绑死单一 Agent、绝对路径或私有工具。
- 可维护性：结构是否清楚，规则、参考资料和脚本是否各归其位。
- 成本：依赖、上下文长度、运行时间和用户交互是否必要。
- 可改造性：补齐差距所需工作是否小于重新实现。

每个候选只能得到一个结论：

- **keep**：原样或仅做命名、路径等机械调整即可满足合同。
- **adapt**：核心可靠，保留有证据的部分，围绕用户需求做有限改造。
- **reject**：硬门槛失败，或在同测中关键能力不达标。
- **invent**：没有候选能安全、经济地满足合同；从零做最小实现，仅吸收可合法复用的通用原则。

默认优先级是 `keep > adapt > invent`，但安全、许可证和用户需求始终高于复用率。

## 5. 维护来源账本

每次调研保留一张简短账本，至少包含：

| 字段 | 记录内容 |
| --- | --- |
| 来源 | 名称、作者/组织、URL 或本地路径 |
| 版本 | 版本号或提交号、查看日期 |
| 许可证 | 类型、适用限制、证据位置 |
| 能力 | 与合同匹配和缺失的部分 |
| 风险 | 权限、依赖、维护和安全发现 |
| 测试 | 使用的同一测试、实测或静态走查结果 |
| 决策 | keep / adapt / reject / invent 及一句话理由 |
| 复用 | 实际保留的原则、文件或代码；需要署名时注明 |

账本应让另一位 Agent 能复核“看过什么、为什么选、具体复用了什么”，不要只保存搜索链接或主观排名。

## 6. 无网络时降级

- 明确写明网络不可用，以及哪些社区和官方来源未能核验；不得伪造候选、许可证、版本或测试结果。
- 继续检查本地 Skill、缓存文档和用户材料，并按相同硬门槛与合同评估。
- 本地已有合格底座时，可产出标注为“本地证据完成、外部调研待补”的版本。
- 本地也没有合格方案时，采用 `invent` 做最小可验证版本，同时列出恢复网络后需要补查的来源和风险。
- 外部核验未完成前，不宣称“社区最佳”“已完成全面对比”或“可安全分发”。
